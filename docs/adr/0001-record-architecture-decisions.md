# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-04

## Context
DataGuard involves many design choices (storage, orchestration, validation, API design). The reasoning behind them is easy to forget and valuable to explain.

## Decision
Significant architecture decisions are recorded as short Architecture Decision Records in `docs/adr/`, numbered sequentially (`NNNN-title.md`) with the sections Status, Context, Decision, and Consequences.

## Consequences
- Decisions and their trade-offs are documented and reviewable.
- Superseded decisions are marked as such, not deleted.
